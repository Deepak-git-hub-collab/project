  - `UPI 2.0 / IMPS`: Virtual Payment Address (VPA) spoofing, QR fraud, and unauthorized collect request traps.

## 🚀 Quick Start

### Prerequisites
- Python 3.11+
- Modern Web Browser (Chrome, Edge, Firefox, Brave)

### Launching the Pipeline
Double-click `start.bat` or run in PowerShell:
```powershell
.\start.ps1
```
Or execute directly with Python:
```bash
python run.py
```

The system automatically opens the Command Center at:
`http://127.0.0.1:8000`

ShieldPlus AI's machine learning model and streaming simulator are grounded on:
1. **Benchmark Ground-Truth Dataset**: European Cardholder Credit Card Fraud Detection benchmark (Kaggle / ULB Machine Learning Group, 284,807 transactions) with highly imbalanced class distributions.
2. **IEEE-CIS / PaySim Synthetic Financial Pipeline**: Synthetic multi-rail omnichannel transaction schemas simulating UPI, Wire, Net Banking, and ATM networks with real-world geographical coordinates across 10 global jurisdictions.
